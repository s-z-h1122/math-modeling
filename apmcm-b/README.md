# 2026 APMCM B 题代码与复现

本项目从赛题的 10 个原始 XLSB 附件生成三维光谱、耗氧与烟气曲线、时滞估计和逐炉留出预测。原始数据保留在题源包中。

## 运行

从题源包解压 `Data.7z`，将下方的 `C:\路径\Data` 替换为直接存放 10 个 XLSB 的目录。使用 Python 3.12，在本项目目录打开 PowerShell。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py --data "C:\路径\Data" --out results
```

## 方法

**Q1 光谱重建。** 每个附件使用自己的波长表头。将负值、非有限值和饱和值标记为异常候选，沿时间轴插补，再用局部中位数及相邻观测筛查孤立尖峰。按每炉物理波长轴对时间和波长依次作形状保持三次插值，在显示网格上评估得到三维光谱。异常筛查阈值是工程设定。

**Q2 耗氧、烟气及延迟。** 对清洗后的耗氧量以 5 s 间隔和最后一个点为节点做单调重建，求连续模型的导数得到氧枪流量。用较宽的节点间隔减少读数阶梯放大成流量尖峰的影响。对 CO₂ 和 CO 分别作连续重建并积分得到累计排放。烟气瞬时体积流量的单位为 m³/s，累计量的单位为 m³。各炉输出六条曲线及其 0.25 s 网格。另报告累计耗氧与烟气瞬时流量及累计排放的 Spearman 相关系数。累计量共同随时间增长，相关系数按描述性结果解读。

时滞扫描以 100 s 窗口内的耗氧流量变化与后续烟气变化作相关，候选时滞为 0–120 s，步长为 2 s。峰值相关系数至少为 0.25，且相对相隔至少 10 s 的其它候选峰高出至少 0.05 时，记录为通过筛查。用于分档汇总和 Q3 校准的窗口还排除搜索边界。分档依据 12 s 后向氧流估计的窗口中位数。相关峰代表数据中可观察的响应时间，包含冶炼过程响应与测量链路影响。

**Q3 跨炉预测。** 在线光谱预处理依次用前值填补异常样本和 3 帧后向中位数平滑。用统一的 24 个物理波段和逐炉波长轴上的谱线特征构造 55 维输入，再加 20、60、150 s 后向窗口的均值和标准差，共 385 维。脚本对每炉检查截断前缀与整段计算的前缀结果一致。每个留出折的特征标准化、40 维 PCA、目标标准化、模型和时滞校准均使用训练炉次。训练标签取自 Q2 在训练炉上重建的烟气曲线，留出炉按原始分析仪读数计分。

固定时滞下对照 HGB、RBF-SVR、ELM、正则 ELM 和小型 MLP，并提供只依赖历史炉次和冶炼经过时间的基准。各模型采用固定超参数。ELM、正则 ELM 和 MLP 分别运行 3 个种子，汇总榜使用三次预测的均值，单种子分数和收敛记录保留在结果表。组合方案包括按波长网格训练两组专家后等权平均，以及把全局 HGB 与同组专家等权组合。

时滞对照另用 HGB，在相同烟气目标时间戳上比较同刻、固定时滞和随流量变化的时滞。固定时滞取训练炉次的炉内时滞中位数，再对各炉取中位数。变时滞在训练折内拟合非递增等距回归。该约束来自题意，分档表保留未强制单调的测量结果。变时滞需要当前及历史耗氧观测来确定发报时点，主要模型比较的预测特征使用光谱。正时滞版本预测的是未来分析仪读数，各版本的提前量随预测记录给出。

附件 1 的两个原始烟气目标均为常数零。该炉依然生成留出预测，分开记录对原表零值的误差。常数目标的 R² 留空，该炉也排除于模型训练和汇总指标，避免把无法确认有效性的零值当作普通监督标签。

## 输出

| 文件 | 内容 |
|---|---|
| `input_manifest.csv` | 炉次、样本数、波长范围和原始附件 SHA-256 |
| `q1/*_spectrum.png`、`q1/spectral_audit.csv` | 十炉三维图与清洗计数 |
| `q2/*_signals.csv`、`q2/*_signals.png` | 十炉六条连续曲线及网格值 |
| `q2/gas_totals_and_associations.csv` | 排放累计量与耗氧相关性 |
| `q2/delay_windows.csv`、`q2/delay_by_flow.csv` | 时滞候选峰、筛查状态与分档统计 |
| `q3/metrics.csv`、`q3/per_heat.csv` | 炉均、合并及逐炉误差 |
| `q3/metrics_matched_timestamps.csv` | 相同分析仪目标时刻的时滞方案对照 |
| `q3/predictions.csv.gz` | 各模型的发报时刻、目标时刻、提前量及真实与预测流量 |
| `q3/seed_and_runtime.csv`、`q3/fold_delay_calibration.csv` | 单次拟合与预测耗时、种子和折内时滞 |
| `run_metadata.json` | 本次复现的环境版本和运行配置 |

交付包的 `results/legacy/` 保留参考工程自带的窗口模型结果，以及本次在原始附件上依次运行旧工程的 Q1 清洗、Q2 烟气处理、Q3 特征构造和窗口模型所得的结果。旧流程使用全炉光谱归一化，且与新流程的时滞标签、波长特征和评估样本口径存在差异。

评估采用同一工厂的逐炉留出，适用范围由这组炉次决定。批量运行验证了输入的时间可用性，工厂采集系统的在线端到端耗时仍需实测。
