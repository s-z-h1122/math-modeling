## 一、数据合格判定标准（输入门禁 + 输出验收）

### 1. 输入侧：原始光谱数据的 4 级异常判定标准（何为“不合格点/帧”）

| 层级 | 判定对象 | 量化判据（硬件边界 / 物理规律 / 统计准则） | 对应处理动作 |
| :---: | :--- | :--- | :--- |
| **L0** | 表级与结构完整性 | 无 `NaN`/`Inf`/非数值，序号 `seq` 严格连续；单炉波长单调递增；记录 `Att05` 仅 775 行（387.5 s）及 6B/6C 波长网格差 1.15–4.71 nm | 按真实物理秒数与原波长域建模；Q3 导出时重采样至 `341–1023 nm` 公共网格 |
| **L1** | 传感器级缺陷（固定坏列 & 饱和） | ① **饱和点**：$I(t_i,\lambda_j) \ge 65535$（16-bit ADC 硬上限）；<br>② **暗区固定坏列**：$\lambda < 420\text{ nm}$ 时间中位数谱偏离局部光滑底噪 $> 6\hat{\sigma}$，放宽连通宽度至 1–7 px（一次性覆盖 6C `383.29–384.03 nm` 热像素及其拖尾、`340–355 nm` 边缘缺陷）；<br>③ **辐射区固定坏列**：跨帧持续异常率 $> 50\%$ 且与左右邻列时间相关系数极低（区别于真实原子峰） | 固定坏列整列掩码；饱和点进入 L2 两类分治 |
| **L2** | 帧级宏观异常（黑帧 & 全波段过曝闪帧） | 在有效吹炼区（由宽窗高分位包络门控，避开起吹暗区）：<br>① **整帧遮挡黑帧**：扣暗基线后主带能量（`550–950 nm`）满足 $E(t) < \alpha\,\hat{E}_{\text{env}}(t)$（$\hat{E}_{\text{env}}$ 为宽窗 `W=41–61` 的 75%–80% 滑动上包络，可抗连续 15+ 帧黑帧，$\alpha \approx 0.5$）；<br>② **全波段过曝闪帧**：单帧饱和列数 $n_{\text{sat}} > 30$ **或** 未饱和蓝光区（`420–500 nm`）相对上包络倍率 $r_{\text{blue}} > 1.6$；<br>③ **局部峰顶窄饱和**：$1 \le n_{\text{sat}} \le 30$ 且 $r_{\text{blue}} \le 1.5$（如 Att02/04/07） | ①② 判为**整帧废帧**（剔出基学习集合 $\mathcal{T}_{\text{good}}$，后续沿时间轴重构）；<br>③ 保留该帧，仅掩码饱和列并施加**右删失约束 $\hat{I} \ge 65535$** |
| **L3** | 点级瞬态毛刺（宇宙射线 / 电噪声） | **时空联合双检**：某像素须**同时**满足：① 波长维 5 点中值残差超局部异方差阈值 $|I_{i,j}-\text{med}_{5,\lambda}| > k_\lambda \hat{\sigma}_{i,j}$；② 时间维 3 帧中值残差超阈 $|I_{i,j}-\text{med}_{3,t}| > k_t \hat{\sigma}_{i,j}$（前后帧同波长无同步峰） | 仅将双检命中的孤立瞬态点置入点级掩码，**零误杀 FWHM 4–7 px 的 Na/K 真实原子峰** |

### 2. 输出侧：问题一重构结果的 5 条硬验收标准（Pass / Fail）

每炉重构曲面 $\widehat{I}(t,\lambda)$ 必须通过以下全部 5 条自动化量化检验，方可判定为“合格”：

1. **物理底线零违背（Hard Physical Check）**
   - 无 `NaN`/`Inf`；非负性满足 $\widehat{I}(t,\lambda) \ge 0$（且暗区无明显振铃下冲）；局部峰顶窄饱和点满足右删失约束 $\widehat{I}(t_i,\lambda_j) \ge 65535$。
2. **4 类异常彻底清除（Residual Anomaly Check）**
   - 6C `383.29 nm` 固定热像素重构后与邻域底噪偏差 $\le 2\sigma_{\text{dark}}$；
   - 有效吹炼区无断崖式黑帧空洞与 65535 平顶截断；
   - 残余瞬态孤立脉冲率 `< 0.01%`。
3. **真实原子发射峰零削峰保真（Peak Fidelity Check — 核心红线）**
   - 在好帧 $\mathcal{T}_{\text{good}}$ 上，Na 589 nm、K 766.5 nm、K 769.9 nm 三大特征峰峰值高度相对偏差 **`< 2.0%`**，峰位漂移 **`< 0.3 nm`（< 1 像素）**；
   - 端到端盲测中，L3 检测器对真实 Na/K 峰区的误杀率 **`< 0.5%`**。
4. **干净区残差精准贴合真实散粒噪声底（Noise-Floor Check — 防过拟合/欠拟合）**
   - 在好帧非异常点上计算残差 $R = I_{\text{raw}} - \widehat{I}$：
     - 暗区 $\text{RMSE}_{\text{dark}} \in [0.8\,\sigma_{\text{dark}},\; 1.3\,\sigma_{\text{dark}}]$（约 `28–48`）；
     - 亮区 $\text{RMSE}_{\text{bright}} \in [0.8\,\sigma_{\text{bright}},\; 1.3\,\sigma_{\text{bright}}]$（约 `70–210`）；
     - 残差在 Na/K 特征峰位置无系统性正负峰形残留（均值接近 0）。
5. **端到端盲测显著优于基线（End-to-End Benchmark Check）**
   - 在干净段注入真实烈度异常（11 帧连续黑帧 + 650 列且蓝光 3× 暴涨闪帧 + 2 px 带拖尾热像素 + 1 px 孤立毛刺），**端到端盲测**（含自动检测 + 修复重构）：
     - 异常检测 Precision / Recall / F1 全面领先（目标 F1 `> 0.90`）；
     - 重构 Masked RMSE 与峰值保真度显著优于“2D 中值+SG 基线”、“强清洗 2D B-样条”以及“未白化原版 GD-SVD”。

## 二、问题一 v2.0 算法主干（修正全部 4 项 Blocker）

1. **Step 1：四级物理分型掩码检测（L0–L3）**
   - 固定坏列标定 → 宽窗高分位上包络黑帧检测 + 蓝光倍率/饱和列数双判据闪帧分治 → 时空联合双检瞬态毛刺。
2. **Step 2：两阶段解耦 + 列方差白化低秩补全去噪**
   - **Stage 2a（好帧子集 $\mathcal{T}_{\text{good}}$ 白化低秩求解）**：稳健估计各波长列噪声 $\hat{\sigma}_j$，构造列白化矩阵 $\tilde{X}_{ij} = (X_{ij}-\mu_j)/\hat{\sigma}_j$，在好帧上运行 Masked Soft-Impute / 加权迭代低秩（对局部窄饱和施加 $\hat{I} \ge 65535$ 投影约束），并通过**白化 Gavish-Donoho 阈值 + 矩阵留出交叉验证（Bi-CV）**确定物理秩 $K$（预期稳定落回 $K \in [10, 18]$），还原尺度得到干净光谱基 $\{\phi_k(\lambda)\}_{k=1}^K$ 与好帧时间载荷 $\{c_k(t_i)\}_{i \in \mathcal{T}_{\text{good}}}$；
   - **Stage 2b（好帧节点跨空洞时间重构）**：仅以好帧时间集合 $\mathcal{T}_{\text{good}}$ 为有效观测点（黑帧与整帧闪帧权重置 0），按各阶主成分 $c_k(t)$ 的信噪比做加权平滑三次 B-样条（或 PCHIP + 温和保形平滑）跨越连续黑帧与闪帧，彻底消除 EM-SVD 整行退化与 GCV 伪零噪声陷阱。
3. **Step 3：解析 $C^2$ 连续二维曲面与双口径交付**
   - 波长维干净基 $\mu(\lambda), \phi_k(\lambda)$ 在真实非均匀波长节点上采用 `not-a-knot` 三次 B-样条插值（绝不二次平滑削峰）；
   - 合成严格 $C^2$ 解析曲面 $\widehat{I}(t,\lambda) = \max\Big(0,\; \tilde{\mu}(\lambda) + \sum_{k=1}^K \tilde{c}_k(t)\tilde{\phi}_k(\lambda)\Big)$；
   - **双口径输出**：① 原始物理量纲 + 各炉原波长域（用于问题一全部 10 炉连续 3D 光谱图，绘图采用特征峰邻域加密/峰值保留降采样）；② 扣暗基线 + 重采样至 `341.0–1023.0 nm` 公共网格（供问题三跨炉建模，同时保留固定公共基单帧在线投影接口以满足 Q3 实时因果性）。
